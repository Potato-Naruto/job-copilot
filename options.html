Job Copilot

Everything is stored locally in your browser. The only network calls go to your chosen AI provider (Gemini, or Ollama on your own machine).

1. AI provider

Used for the recruiter analysis, cover letters, resume tailoring and resume import. Autofill itself works without any AI.

Default gemini-3.8-flash (free tier). Alternatives: gemini-3.5-flash-lite, gemini-3.1-flash-lite. Get a free key at aistudio.google.com/apikey. Stored only in this browser. Note: on the free tier Google may use prompts to improve its products — your resume is sent in each request. Use Ollama if that matters.

How to connect Ollama

  1. Install Ollama from ollama.com/download and make sure it's running (tray icon on Windows).
  2. Pull a model, e.g. in a terminal: ollama pull llama3.1:8b (better quality: qwen2.5:14b or gemma2:9b). Small models write weaker letters and sometimes break the JSON output.
  3. Leave the URL as http://localhost:11434, click Detect installed models, pick one.
  4. The extension removes the browser Origin header for local requests, so this normally just works. Only if you still get "403 / Origin blocked" (e.g. Ollama on another machine), allow the extension origin and restart Ollama. Windows (PowerShell): setx OLLAMA_ORIGINS "moz-extension://*" then quit and reopen Ollama. Mac/Linux: OLLAMA_ORIGINS="moz-extension://*" ollama serve.
  5. Click Test connection below. Everything then stays on your machine.

2. Import your resume

Paste the text of your resume, then let the AI turn it into your structured profile (review and edit below). Existing non-empty values in your profile are overwritten by what's parsed.

3. Personal details

4. Work & application preferences

Used for the standard screening questions. Yes/No fields match the form's options automatically.

5. Voluntary self-identification (optional)

Leave blank to be asked each time, or enter e.g. Decline to self-identify — it will match "prefer not to say" style options.

6. Resume content

The source of truth for cover letters and tailored resumes. The AI can reorder and reword but is told never to invent employers, titles, dates or metrics. Edit the JSON freely (summary, experience, education, skills, projects, certifications).

7. Resume file to attach

Attached to resume upload fields when you autofill (a tailored PDF can replace it per application).

8. Remembered answers

Questions the extension didn't know — saved the first time you answered them, reused on every future application. Edit or delete freely, or pre-seed your own.
